# Seminar topics for the Introduction to Programming course in C++.

## Winter Semester 2025/2026, Information Systems

- [Topic 1](./Topic-01): Introduction. Primitive data types. Type conversions. Operators.
- [Topic 2](./Topic-02): Conditional statements — `if`, `switch`, and the ternary operator.
- [Topic 3](./Topic-03): Loops. The `break` and `continue` statements.
- [Topic 4](./Topic-04): Functions.
- [Topic 5](./Topic-05): References and pointers.
- [Topic 6](./Topic-06): Arrays. Basic operations, traversal, and searching. Multidimensional arrays.
- [Topic 7](./Topic-07): Character strings.
- [Topic 8](./Topic-08): Number systems. Bitwise operations.
- [Topic 9](./Topic-09): Memory architecture and memory management.
- [Topic 10](./Topic-10): Recursion.
